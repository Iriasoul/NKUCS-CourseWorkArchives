## 2. 选题

### 2.1 一句话

**单架配送无人机的最优送餐顺序问题** —— 即**带时间窗的旅行商问题（TSP with Time Windows, TSPTW）**：一架无人机从起降站出发，把已装载的 $k$ 份外卖按某顺序送达 $k$ 位客户后返回，在满足各客户送达时限的前提下最小化总完成时间。用暴力、动态规划、DP + 时间窗剪枝三种精确方法求解并对比。

### 2.2 为什么选它（写进报告的"问题背景/选题动机"）

- **现实性与前瞻性**：无人机外卖配送（低空经济）是正在落地、贴近生活的近未来场景。
- **三层都干净可分析**：暴力 $O(k!)$、Held-Karp DP $O(2^k k^2)$、DP+剪枝（同一最优、实测更快），每层都有精确复杂度，正中本课"重可解释性/可分析性"的要求。
- **简化历程（可在报告里点一句，体现思考过程）**：最初考虑的是多机带拼单的派单（RTV 图 + 整数规划），但其顶层是 NP 难、只能上 ILP/启发式，给不出干净的复杂度界；遂**收缩到单机 TSPTW**这一自洽子问题，保住"每层精确可分析"这一最被看重的性质。本质上：*重点不在问题多复杂，而在能否清楚地体现算法思想*。

## 3. 问题形式化（核心模型）

### 3.1 锁定假设（核心版；扩展见 §9）

- 单架无人机，$k$ 份外卖在站点**一次性装载完毕**（取餐已完成，故无取送先后问题，退化为纯配送）。
- **硬时限**：每位客户有一个最晚送达时刻 $L_i$；超过即不可行。*选硬时限是为让 DP 保持标量、令时间窗能直接剪枝；软罚分见 §9。*
- **直线飞行**：飞行时间 = 欧氏距离 / 航速。
- 核心模型**暂不含电量约束**（其会使代价依赖到达时刻、需标号 DP，归入 §9 扩展），核心专注于干净的 TSPTW。

### 3.2 集合与参数

| 符号 | 含义 |
|---|---|
| $0$ | 起降站（路线的起点与终点） |
| $1,\dots,k$ | $k$ 位客户（= $k$ 份订单） |
| $L_i$ | 客户 $i$ 的最晚送达时刻（硬时限） |
| $t_{ij}$ | $i\to j$ 飞行时间 $=\lVert i-j\rVert/\text{speed}$ |
| $\theta$ | 每个客户点的卸餐服务时间（常数，可设 0） |

参数均作为**实例输入**，不写死（见 §3.5、§6）。

### 3.3 一条航线及其可行性

一条航线是客户的一个排列 $\pi=(\pi_1,\dots,\pi_k)$，路径为 $0\to\pi_1\to\dots\to\pi_k\to 0$。沿途递推到达时刻 $A_{\pi_m}=\sum_{l=1}^{m} t_{\pi_{l-1}\pi_l}\,(+\,(m{-}1)\theta)$，其中 $\pi_0=0$。**可行**当且仅当每个客户 $i$ 满足 $A_i \le L_i$。

### 3.4 目标

最小化**总完成时间**（无人机返回站点的时刻）：

$$
\min_{\pi\ \text{可行}}\ \Big(\textstyle\sum_{m=1}^{k} t_{\pi_{m-1}\pi_m}\Big) + t_{\pi_k\,0}\ (+\,k\theta)
$$

> 因外卖只有"最晚"约束、无"最早"约束，途中不需等待，到达时刻 = 累计飞行时间，故总完成时间路径可加，DP 可用标量。

### 3.5 参数即输入（实例 schema，供数据生成与代码 I/O 共用）

- 全局：`speed`、`theta`、站点坐标。
- 每个客户一行：`id, x, y, L`（最晚送达时刻）。
- 求解器只消费这些数值与一个距离函数；**距离函数可替换**（欧氏 → 路网矩阵）而不动算法 —— 这是报告里论证"算法普适性"的依据。

## 4. 三层算法设计

### 4.1 第一层 · 暴力（baseline + 标准答案）

枚举全部 $k!$ 个排列，对每个递推到达时刻、检查所有时限、计算总完成时间，取可行解中的最小。
- **复杂度**：$O(k!\cdot k)$。仅 $k\lesssim 11$ 可用。
- **用途**：小规模下作为后两层的**最优性校验标准答案**。

### 4.2 第二层 · Held-Karp 状态压缩 DP（课程算法）

状态 $dp[S][j]$ = 从站点出发、恰好送达集合 $S$ 中全部客户、当前停在 $j\in S$ 的**最早到达 $j$ 的时刻**。

$$
\textbf{初始：}\quad dp[\{j\}][j]=t_{0j}\quad(\text{仅当 } t_{0j}\le L_j)
$$
$$
\textbf{转移：}\quad dp[S][j]=\min_{i\in S\setminus\{j\}}\Big(dp[S\setminus\{j\}][i]+t_{ij}\Big)\quad(\text{保留当且仅当 }\le L_j)
$$
$$
\textbf{答案：}\quad \min_{j}\Big(dp[\{1..k\}][j]+t_{j0}\Big)
$$

- **复杂度**：时间 $O(2^k k^2)$，空间 $O(2^k k)$。约 $k\le 18\text{–}20$ 可解。
- **分治/课程思想**：把"经过某子集结尾于某点"的子问题最优解组合出整体最优，是状态压缩 DP 的教科书形态，分析极干净（与范文里 KD-Tree 的"分治构建"地位相当）。

### 4.3 第三层 · DP + 时间窗状态消减 + 下界剪枝（杀招）

在第二层 DP 之上，用三类剪枝把指数状态空间在实测中大幅压缩，**最优解不变、速度大增**（对应范文里 KD-Tree 的"边界框剪枝"优化）：

1. **时间窗状态消减**：任何 $dp[S][j]>L_j$ 的状态直接丢弃；转移时提前判违例即剪。
2. **下界剪枝（分支限界式）**：维护当前最优完整解 `incumbent`；对状态 $(S,j)$、当前时刻 $\tau=dp[S][j]$，对剩余客户 $R=\{1..k\}\setminus S$ 计算一个**可采纳下界** $LB(S,j)$（如：$R$ 上的最小生成树 + 进出 $R$ 的最小衔接边；或各剩余点最小入边之和的简化下界）。若 $\tau+LB\ge$ `incumbent` 则剪去该状态。
3. **支配**：同一 $(S,j)$ 仅保留最小值（标量 DP 天然满足）；跨状态支配属 §9 标号扩展。

- **论文背书**：Dumas 等 1995 的精确 TSPTW 算法即"Held-Karp 型 DP + 利用时间窗的消减测试缩减状态空间与转移数"；其在求解前与求解中均做消减，可精确求解约 200 节点的实例。详见 §8。
- **关键直觉**：让剪枝生效的"时间窗"，正是外卖的送达时限 —— 应用与算法互相成就。

### 4.4 复杂度对照表

| 层 | 方法 | 时间复杂度 | 适用规模 | 是否精确 |
|---|---|---|---|---|
| 一 | 全排列枚举 | $O(k!\,k)$ | $k\lesssim 11$ | 是 |
| 二 | Held-Karp DP | $O(2^k k^2)$ | $k\le 18\text{–}20$ | 是 |
| 三 | DP + 时间窗剪枝 + 下界 | 最坏同二层；实测远小于 $2^k$ | 同二层、更快 | 是 |

> 三者求解同一目标；第三层 = 第二层 + 剪枝，第一层 = 无任何剪枝的穷举。这条"基础 → 剪枝优化"的嵌套主线，与范文完全同构，是报告"可分析性"的核心论点。

## 5. 串行与并行

- **串行（重点）**：三层算法本身，尤其 DP 与剪枝逻辑 —— 报告主体与分析对象。
- **并行（次要，横向贯通用）**：
  - 暴力层：按首个客户/排列前缀切分到多线程，天然独立。
  - DP 层：按 $|S|$（popcount）**分层**，同层各状态相互独立，可 OpenMP 并行该层全部转移。
  - 多实例并行：批量算例并行求解。
  - 针对性串行优化（横向贯通要求的）：位运算枚举子集、下界缓存、迭代加深、`incumbent` 早得（先跑一遍最近邻启发式给初值）。

## 9. 扩展方向（可选加分，明确非核心）

每一条都把核心模型自然加厚，且都有对应文献支撑：

- **软时限**：把迟到从硬约束改为目标罚项 $\lambda\sum\max(0,A_i-\bar d_i)$。此时代价依赖到达时刻，标量 DP 失效，需 **(到达时刻, 累计代价) 的 Pareto 标号 DP + 支配**（即 Lera-Romero 2022 路线）。
- **电量约束**：整趟能耗 $\le$ 电池；能耗随距离与载重变化，构成第二资源维，需资源约束标号 DP。
- **出餐时间**：客户/餐厅带就绪时刻，取餐不早于该时刻（引入"最早"约束与等待）。
- **多站点 / 多无人机带拼单**：回到最初的派单模型（RTV 图 + ILP），作为远期展望提及即可。
- **时间相关航时**：风速/空域拥堵使 $t_{ij}$ 随时间变 → 时间相关 TSPTW（接 Lera-Romero 2022）。
