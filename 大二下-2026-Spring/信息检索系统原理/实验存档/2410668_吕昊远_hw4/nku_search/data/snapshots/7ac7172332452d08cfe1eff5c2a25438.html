南开大学学生就业指导中心代发
工作地域：北京市 / 上海市 / 浙江省 / 广东省
职位类别： -
学历要求：本科 / 硕士研究生 / 博士研究生
发布时间：2026-03-29浏览量：2195

* 职位描述：

RISC-V架构的AICPU芯片企业。公司致力于通过全栈核心技术自研，对外提供终端AICPU芯片、云端服务器AICPU芯片、云端AI推理芯片等计算产品和计算系统，推动RISC-V+AI+Trtion/Tilelang智算生态普及，助力Al计算机、AI机器人等未来产业的发展。

公司在北京、杭州、珠海、上海、深圳、西安等地设有办公室。公司持续推动全球RISC-V量产技术和产品的前进，最新一代高性能RISC-V CPU核的单核性能超过16分/GHz SPECINT2006,应用于云数据中心、智算中心等领域，是全球可量产的性能最高的RISC-VCPU核。

2026年1月发布RISC-VAICPU芯片K3,单芯片以RISC-V统一指令既能提供CPU通用算力又能提供AI智能算力，实现对传统CPU的智能化升级。K3芯片在全球RISC-V领域创造多项第一，第一颗符合RVA23最新国际标准的RISC-V芯片，第一颗支持1024bit超宽向量计算的RISC-V芯片，第一颗支持FP8原生推理的RISC-VAI芯片等。K3芯片适合运行30B-80B大模型，面向AI机器人、Al+等增量市场。

公司芯片量产能力业界领先。2024年4月发布的RISC-VAICPU芯片K1累计量产超过15万颗，是全球量产数量最多的RISC-V算力芯片，是行业首个获得“中国芯”权威奖项的RISC-V芯片。

公司是国内RISC-V赛道融资金额最多的算力芯片企业之一。股东阵容包括北京市、中国香港特区政府等最大政府投资平台;中国互联网投资基金、中国农业银行AIC等国家级平台;君联资本、联想创投、经纬创投、华夏恒天等知名市场化资金。

公司坚持以人为本，注重青年人才培养，不断发展人才队伍，形成支撑公司长远发展的高素质人才梯队。欢迎CPU、AI、软件等领域的同仁加盟，为中国芯贡献一份力量。
